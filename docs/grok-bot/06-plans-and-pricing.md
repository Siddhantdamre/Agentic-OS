# Plans, pricing, availability

Grok Bot is **bundled, not sold standalone**, and has no published free tier.

| Plan | Price | Notes |
|---|---|---|
| Cursor Ultra | $200 / month | Bot computer, tool sign-ins, routines, extended tokens |
| Cursor Teams Premium | $120 / seat / month | Central billing, team marketplace, shared analytics, SSO |
| Cursor Pro | $20 / month | Included per later reviews; Pro+ and Teams Standard also eligible per the announcement |
| SuperGrok | $30 / month | Base paid tier; eligible per announcement |
| SuperGrok Plus | included | Eligible per announcement |
| SuperGrok Heavy | included, about $99 / month promo (from $300) | Heavy is the tier reviewers tested |
| Enterprise | sales / waitlist | Admin controls, network policy, audit, action recording |

- **Usage:** weekly allowance that resets weekly; overage billed at model rates.
  Exact token numbers are not published. Separate from normal Grok/Cursor quota.
- **Status:** beta, announced 2026-08-11.
- **Platforms:** desktop (macOS, Windows, Linux) and iOS; Android and iPad coming.
- **Requirement:** account that allows cloud data storage (Legacy Privacy Mode
  is incompatible).
- **Teams vs Enterprise:** Teams enables Grok Bot by default; Enterprise needs
  admin activation and adds Action Recording, audit logs and network policy.

Prices disagree between reviews (the first review said Bot access started at Ultra
or Heavy; later ones say Cursor Pro is included). Treat them as unconfirmed.
Team Bots (public beta, Teams and Enterprise) has no published price.
